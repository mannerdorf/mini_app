# RuStore — скриншоты HAULZ

## Почему отклонили

RuStore **обрезает** загруженные изображения до **9:16** (телефон, портрет). Если файл другого соотношения или снят как «длинный скролл», в карточке остаются **обрезанные слова, кнопки и логотип** — модерация отклоняет.

## Требования RuStore (телефон)

- Минимум **3**, рекомендуется **6–8** скриншотов
- **Вертикальные**, одна ориентация во всём наборе
390×844 CSS-viewport + scale → **1080×1920** PNG. CSS-viewport **360×640** (ширина ≤768px) — мобильная вёрстка, не desktop.
- Формат **PNG** или JPG, **≤ 3 МБ** на файл
- На скрине **полностью** видны заголовок, кнопки, поля, нижнее меню (если есть)

## Сгенерировать скриншоты

На Mac (после `npm ci`):

```bash
cd ~/mini_app
npx playwright install chromium

# Гостевые экраны (лендинг, калькулятор, склады, FAQ, вход)
node scripts/capture-rustore-screenshots.mjs

# + экраны ЛК (нужен тестовый логин)
STORE_LOGIN='demo@example.com' STORE_PASSWORD='***' \
  node scripts/capture-rustore-screenshots.mjs --app
```

Файлы: `store/rustore/screenshots/*.png`

## Загрузить в RuStore Console

1. Карточка приложения → **Скриншоты** → **Телефон** → **Вертикальная**
2. Удалите старые скриншоты с обрезанным текстом
3. Загрузите **в порядке номеров** (`01-guest-home.png` … `05-login.png`, при наличии `06–08`)
4. Проверьте превью в консоли: **нет обрезанных кнопок и букв**
5. Отправьте на модерацию повторно
