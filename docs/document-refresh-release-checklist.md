```bash

```
Если Git сообщает о пересечении локальных изменений — остановиться, ничего не сбрасывать.

Ручная проверка новых очередей (на cron-VPS):

```bash
/opt/haulz/cron-call.sh '/api/cron/refresh-cache?kind=invoices&lane=recent'
/opt/haulz/cron-call.sh '/api/cron/refresh-cache?kind=perevozki&lane=active'
tail -n 20 /var/log/haulz-cron-call.log
```
Ответ skipped/not_due_or_running допустим, если задание уже запускалось. Это не подтверждение новой загрузки. Проверять завершённые результаты и ошибки.
