# Сценарии общения с Алисой (навык Холз)

Документ для тестирования, документации и доработки голосового помощника HAULZ в Яндексе Алисе.

---

## 1. Первый запуск и авторизация

| Шаг | Пользователь | Алиса |
|-----|--------------|-------|
| 1.1 | «Запусти навык Холз» | Приветствие и предложение ввести код авторизации из мини-приложения. |
| 1.2 | (без кода) «Что актуально?» | «Авторизуйтесь, пожалуйста. Введите код авторизации из мини-приложения Холз.» |
| 1.3 | Пользователь открывает мини-приложение → Профиль → Голосовые помощники → Получить код для Алисы. | — |
| 1.4 | «Код 123456» / «123456» | «Вы авторизованы под компанией [Название компании]. Я Грузик, AI-помощник HAULZ. Чем я могу вам помочь?» |
| 1.5 | Неверный или истёкший код «999999» | «Код не найден или истек. Получите новый код в мини-приложении.» |

Важно: у привязанного пользователя шестизначный номер перевозки не должен восприниматься как код авторизации.

---

## 2. Главная сводка: что актуально

| Пользователь | Алиса |
|--------------|-------|
| «Что актуально?» / «Дай сводку» / «Что нового?» | Приоритетная сводка: задержки, счета к оплате с суммой, грузы в пути, на доставке, доставленные, принятые. |
| «Кратко по перевозкам» | То же. |
| «Что в работе?» | Поддерживается как скрытый совместимый синоним, но клиенту не показывается как основная команда. |

Пример: «Актуально: к оплате 3 перевозки на 245 000 рублей, в пути 5 перевозок, доставлено 1. Хотите список?»

---

## 3. Что требует внимания

| Пользователь | Алиса |
|--------------|-------|
| «Что требует внимания?» / «Есть проблемы?» / «Есть задержки?» | Сначала задержки/риски срока, затем оплаты, затем активные доставки. |
| «Что опаздывает?» / «Что срывается по срокам?» | Список перевозок с риском задержки. |

Если критичных вопросов нет: «Критичных вопросов не вижу: задержек и счетов к оплате нет.»

---

## 4. Статус конкретного груза

| Пользователь | Алиса |
|--------------|-------|
| «Где груз 135702?» | Статус, маршрут, даты, оплата, документы, предложение отправить подробности. |
| «Что с перевозкой 0135702?» | То же. Номер с ведущим нулём и без него ищется одинаково. |
| «Когда приедет 135702?» / «Найди груз 135702» | То же. |
| «Где груз?» | «Назовите номер перевозки.» |

Правило номера: для поиска сравнивается нормализованный номер без ведущих нулей, в тексте можно показывать оригинальный номер из 1С.

---

## 5. Оплаты и задолженность

| Пользователь | Алиса |
|--------------|-------|
| «Что надо оплатить?» / «Есть задолженность?» | Количество перевозок к оплате, общая сумма, номера первых перевозок. |
| «Какие счета не оплачены?» / «Сколько к оплате?» | То же. |
| «Подробнее» / «Да» после ответа | Таблица: номер / дата / кол-во / плат вес / сумма. |

---

## 6. Перевозки, доставки и периоды

| Пользователь | Алиса |
|--------------|-------|
| «Что в пути?» / «Какие грузы едут?» | Краткий список перевозок в пути. |
| «Что доставлено сегодня?» | Доставленные перевозки за сегодня. |
| «Что пришло вчера?» | Доставленные перевозки за вчера. |
| «Какие грузы на доставке?» | Перевозки в статусе «На доставке». |
| «Что было за неделю?» / «Что за месяц?» | Сводка за период. |

---

## 7. Документы голосом

| Пользователь | Алиса |
|--------------|-------|
| «Пришли счёт по грузу 135702» | Создаёт короткую ссылку на документ и возвращает её в тексте ответа. |
| «Есть УПД по перевозке 135702?» | То же для УПД. |
| «Нужна экспедиторская расписка» | Уточняет номер перевозки, если номер не назван. |
| «Отправь документы в чат» | Уточняет тип документа или номер, если данных не хватает. |

Ссылки не диктуются голосом как основной сценарий; они доступны в тексте ответа Алисы.

---

## 8. Управление компанией

| Пользователь | Алиса |
|--------------|-------|
| «Какая компания выбрана?» | Называет текущую компанию. |
| «Работай от имени компании [название]» | Переключает компанию, если она привязана. |
| «Переключись на компанию X» | То же. |
| «Отвяжи компанию» | Удаляет текущую привязку. |

---

## 9. Fallback через AI-чат

Если фраза не распознана быстрым intent router, запрос передаётся в `/api/chat` с `channel: "alice"` и контекстом компании.

Примеры:

| Пользователь | Ожидаемое поведение |
|--------------|---------------------|
| «Контакты Холз» | Ответ через базу знаний/чат. |
| «Какой у меня активный заказчик?» | Ответ с текущей компанией. |
| «Что такое платный вес?» | Объяснение через чат. |

При таймауте или ошибке: «Запрос обрабатывается дольше обычного. Повторите запрос через несколько секунд.»

## 11. Тест-кейсы

- [ ] Запуск навыка без кода → просьба авторизоваться.
- [ ] Ввод верного кода → приветствие с названием компании.
- [ ] Ввод неверного/старого кода → сообщение «код не найден или истек».
- [ ] После авторизации «Где груз 135702?» → поиск груза, а не попытка авторизации по коду.
- [ ] «Где груз 0135702?» и «Где груз 135702?» → один и тот же результат.
- [ ] «Что актуально?» → приоритетная сводка.
- [ ] «Что требует внимания?» / «Есть задержки?» → задержки или оплаты.
- [ ] «Что надо оплатить?» → количество, сумма, номера, «подробнее».
- [ ] «Что доставлено сегодня?» → доставленные за день.
- [ ] «Какие грузы на доставке?» → статус «На доставке».
- [ ] «Пришли счёт по грузу 135702» → ссылка на документ или понятная ошибка.
- [ ] «Есть УПД?» без номера → уточнение номера.
- [ ] «Какая компания выбрана?» → текущая компания.
- [ ] «Работай от имени компании X» → переключение при нескольких компаниях.
- [ ] «Отвяжи компанию» → отвязка и предложение получить новый код.
- [ ] «Подробнее» после списка → таблица номер / дата / кол-во / плат вес / сумма.
- [ ] Нераспознанный вопрос → fallback в AI-чат.
- [ ] Таймаут 1С/чата → «Повторите запрос через несколько секунд».
