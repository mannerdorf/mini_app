# T08 — очередь и проверяемые источники

01.10.2026. Продолжение T07. До завершения production-приёмки задача остаётся в работе.

## Что реализовано

- Миграция 124: постоянные задания, попытки, сохранённые тематические задания и пакеты фактов; отдельные настройки бюджета. Начальные значения: платная генерация выключена, бюджет 0, тарифы 0.
- Ключ задания: материал + исходная ревизия + вид работы + выбранные факты + версия реестра/политики. Повторная постановка возвращает то же задание. Удержанное задание можно повторить только до первого обращения к модели и пока исходная ревизия актуальна.
- Одно активное задание; транзакционная блокировка, lease 5 минут. После истечения lease незавершённая проверка возвращается в очередь. Если запрос модели уже мог уйти, задание удерживается, резерв сохраняется, стоимость неизвестна. Автоповтора платного запроса нет. Сохранённая версия пользователя защищена CAS.
- Результат генерации и переход состояния фиксируются вместе с новой ревизией черновика. Публикация не вызывается из worker. Новая ревизия требует отдельной проверки и явного подтверждения редактора.
- Сборщик использует фиксированный реестр T04. Проверяет статус, срок, наличие и SHA-256 исходников; сохраняет факты, ограничения, версии, дату сбора и причины удержания. Записи владельца принимаются только по точной известной ссылке на подтверждение. Новые произвольные URL, файловые пути и RSS не принимаются.
- Исходники frontend проверяются по `/content-source-manifest.json`, который создаётся из файлов текущей сборки сайта. Это исключает сверку со старой копией frontend на API VPS. URL фиксирован, перенаправления запрещены, таймаут 5 секунд, ответ ограничен 20 КБ. Недоступный/устаревший/изменившийся источник удерживает материал. Остальные исходники сверяются на API-сервере.
- Перед публикацией новый издатель ещё раз проверяет источники и срок. DB trigger не позволяет закешированному старому издателю обойти проверку. Старые генераторы отключены в коде и ограничены точечными маршрутами nginx (включая адреса с конечным слешем).
- Детерминированные проверки: заголовки разделов, длина описания, точные дубли опубликованного текста, рискованные числовые обещания, гарантии, специальные грузы/таможенные требования, небезопасное содержимое. Они не доказывают семантическую достоверность всех предложений: проверка смысла, полноты выбранных фактов и экспертная проверка остаются у человека.
- Генератор получает только выбранные подтверждённые факты и ограничения. Старое требование придумывать ценовой ориентир удалено. Ответ обязан указать известные идентификаторы фактов; неизвестные ссылки на факты отклоняются.

## Расходы и выполнение

SDK: без автоматических повторов, таймаут 90 секунд, максимум 2048 выходных токенов. Перед запросом резервируется консервативная стоимость по настроенным ставкам: число UTF-8 байтов задания/пакета плюс запас 4096 на вход и максимум выхода. Проверяется суточный лимит UTC; резервы неопределённых запросов не освобождаются автоматически. Успешные ответы сохраняют токены и расчётную стоимость по зафиксированным тарифам. Это оценка, не счёт провайдера. Цены не зашиты и не выдаются за актуальные: включение требует отдельно согласованного бюджета и проверенных ставок.

В кабинете: выбрать факты → поставить проверку/генерацию → обработать следующее задание → посмотреть источники, попытки и причины удержания. Сохранённая очередь работает между открытиями кабинета. `scripts/media-factory-worker.ts` — отдельный одноразовый клиент обработки через авторизованный API; новый процесс продолжает очередь из БД. Планировщик/постоянный сервис не включались. Исполнение в текущем выпуске выполняет ограниченный API-обработчик; перенос обработчика в отдельный постоянный процесс — при включении фонового режима и измерении нагрузки.

В production не было платной генерации, отправок в каналы или публикации тестовых статей. Подготовленный ранее материал id=1 остаётся черновиком без автора.

## Проверки

38 тестов прошли: реальные SQL-переходы на PGlite, закрытие и повторное открытие БД, идемпотентность, потеря lease до/после запроса модели, неизвестный расход, отключённый бюджет, поздний результат, удержание при конфликте, невозможность обойти издатель, регрессии T06/T07. Модель в тестах заменена детерминированным провайдером; платных вызовов не было. Обе проверки TypeScript и production-сборка прошли. nginx -t проверяет основной API-конфиг и конфиг статики отдельно.

Браузер: настоящий компонент с отдельной локальной БД — выбран подтверждённый маршрут, задание поставлено и выполнено, показаны источники и попытка с расходом $0. Неподтверждённые факты и платная генерация недоступны.

## Границы

Внешние новостные RSS/API и произвольные официальные документы ещё не подключены — это T11/отдельная проверка эксперта. T08 использует утверждённые источники HAULZ из T04. Без согласованных фактов нельзя выпускать материал о таможенных требованиях. Автоматическая фактологическая или юридическая экспертиза не заявляется.
