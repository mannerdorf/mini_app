# Baltic AIS land anomaly mask

Source: Natural Earth 1:10m land, public domain.
https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_land.geojson

Downloaded 2026-10-08; original SHA256:
1ac90796408bc6ad6911d69448485d3c4dbf2190370080368a09976e1c9f7416

Polygon rings clipped to lon 9–34, lat 53–66 with Sutherland–Hodgman,
coordinates rounded to six decimals. Original holes retained. Only use as a
coarse anomaly warning with 500m coastline tolerance, never marine navigation,
route construction or automatic coordinate replacement. Harbours, channels and
coastline changes may not be represented by this small-scale dataset.
